# NoteNest — Personal Digital Notebook & Knowledge Hub

A personal digital notebook and knowledge management platform for organizing notes, checklists, reminders, and study materials.

## Features

- **Multi-category organization**: Multi-category organization: Notes, Checklists, Reminders, Ideas, Travel, Work, and Study Material
- Rich note editor supporting tags, pinning important items, and color categorization
- Interactive checklist items with completion progress indicators
- Quick keyword search and tag filtering across all stored documents
- Clean modern dashboard with greeting HUD and note count statistics
- Persistent offline storage using browser LocalStorage

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage API

## Installation & Setup

This is a standalone, client-side web application. No complex build pipelines, database configurations, or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSManikandaprabu/-NoteNest.git
   cd -NoteNest
   ```

2. **Run the application:**
   - **Direct Browser Launch**: Double-click `NoteNest.html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   - **Or via Local HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000/NoteNest.html](http://localhost:8000/NoteNest.html) in your browser.

## Usage

1. Launch the application in your browser following the setup instructions above.
2. Interact with the application controls and input fields tailored for NoteNest — Personal Digital Notebook & Knowledge Hub.
3. Preferences and data are stored locally in your browser's LocalStorage where applicable.
